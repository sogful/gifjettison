<h1>GifJettison</h1>

this extension just hides gifs from youtube comment sections the way you want to hide them, that's all!
<hr>
<p>to install on chrome, simply <img src=".github\code.svg" width="80"> → <img src=".github\downloadzip.svg" width="100">, enable developer mode in chrome extensions and "load unpacked", pointing to the extracted folder.</p>
to install on firefox, use firefox nightly/dev. if those don't work, then the firefox versions you're installing are too gated and you might need to find a workaround. you can try using the userscript version in releases!

## supported types

- Youtube
- [YouTube GIF Comments](https://chromewebstore.google.com/detail/youtube-gif-comments/fogcfkjicadghgcpicdfgmmdldedgnhl)
- [GifTube](https://chromewebstore.google.com/detail/youtube-gif-comments/mgokeljfnihjbcmblpceeciccjeacpdm) <br>
<sup><sup>(funnily enough, it's also titled "YouTube GIF Comments".. it's called GifTube in the extension for distinction)</sup></sup>
